# 发行验证范围

版本：2.0.1。发布日期：2026-11-11。聊天组件：0.2.3。

本版通过 142 项 Python 用例、8 组 JavaScript 检查、TypeScript 类型检查与前端构建。与 2.0.0 相比，新增 16 项 Python 用例；新增测试文件也收录在源码包中。

- 使用实际非阻塞管道回放 L4、L5、R4、R5 的 HID 数据，串接 F7 手势状态机，覆盖短脉冲后保持录音与真正松开。
- 覆盖固定跟随触发背键、另一颗背键不能延长录音、多键同时按下不猜测、分片与无关报文、同批次按下和松开、设备 EOF 及取消后关闭描述符。
- 覆盖背键状态丢失时取消而不转写、状态丢失后再次收到 F7 脉冲、旧报告隔离、菜单退出、无底层接口时正常 F7 事件、外接键盘、转写取消及双击清空。
- 沿用原版系统接口发现，仅在收到映射功能键后临时读取只读背键报告；不打开手柄控制接口，不获取手柄独占权限，不增加空闲时的报告轮询或录音。
- 沿用旧配置与账号路径、发行源码白名单和隐私排除检查。

本轮发布未安装到任何设备。上述为本地自动验证，四颗背键的游戏内录音、释放、取消、清空及 Steam 菜单操作尚待真机验收。其他掌机以及底层报告接口不可用的设备，不因本次测试通过就视为已兼容；其他麦克风取音/网络识别故障也未在本次解决。

## 2.0.0 基线记录

2.0.0 功能与 alpha.23 一致；聊天组件为 0.2.3。

本版回归：126 项 Python 用例、8 组 JavaScript 检查、TypeScript 类型检查及构建。新增五笔词库校验、旧配置保持、无系统拼音写入、选词/翻页/中英文切换、填入异常保留编码和异步加载期间的菜单优先检查。

与 alpha.22 发行源码对比，语音/账号/F7 手势、原生按键映射、设备发现和会话识别保持；新增方案只在明确选择五笔时启用。

发行检查覆盖：

- 关闭状态只读检测、真实开关提示、异常监听恢复、单设备异常隔离、非 UTF-8 设备名以及隐藏/虚拟键盘元数据。
- 离屏启动参数与独立缩放、二维码超时、组件失败分类、阻止自动反复启动、保留浏览器的二维码刷新。
- 官网二维码格式与来源限制、登录动作次数限制、对话框保护、二维码过期。
- QML 语法解析；开发设备已有真实登录与会话恢复记录，本次未重新扫码测试。

- 新增机身 PS/2、I2C、SPI、USB/蓝牙及右 Ctrl 能力识别；手柄与虚拟设备排除。
- 原游戏模式环境文件、当前用户 Steam 进程回退、复合桌面标记、过期文件、不同用户、显示会话变化和语音共用会话的模拟检查。
- 从模拟设备发现到 Ctrl＋空格唤醒/F7 按住释放的完整后端事件链；权限失败后重试、断连重连及桌面切换释放。

- 只收录指定源文件和公开文档；不导出已登录设备上的插件目录或用户目录。
- 安装 ZIP、源码 ZIP 和聊天组件 ZIP 的完整性、文件清单及 SHA-256。
- 额外放入的模拟 Cookie、个人配置和截图不会进入包；允许路径上的符号链接及模拟凭据会阻止构建。
- 空白用户目录初始化：总开关、键盘和语音默认关闭，未登录，没有浏览器资料，没有自动启动录音或登录浏览器。
- 键盘设置、语音状态、F7 手势、取消、连续听写结果隔离、剪贴板交接、窗口焦点保护和游戏组件升级的回归检查。
- 源码包可以独立重新生成一致的发行包。

2026-11-09，同功能 alpha.23 已安装到开发设备，前后端均加载成功，原设置及账号保留，语音恢复待命；用户已认可当前版本。2.0.0 本次仅更新发行编号、文档与打包清单，输入功能源代码未变。用户也已反馈 GPD 朋友机型的外接键盘问题解决；五笔及 GPD 语音仍未完成真机验收。自动检查使用模拟设备/会话，不等于所有游戏内操作均已验收。
