# 语音输入使用指南

适用于 WoWDeck Input 2.0.0。语音使用个人豆包账号，与外接键盘输入法独立开关；不需要先按 `Ctrl + 空格`，也不要求连接外接键盘。

## 1. 安装并扫码登录

1. 按 [安装说明](../INSTALL.md) 安装 `WoWDeck-Input-2.0.0.zip`。
2. 在游戏模式打开 Decky → **WoWDeck Input**，打开顶部 **总开关**。
3. 打开 **语音输入 → 启用语音输入**，进入 **语音设置**。
4. 等待二维码出现，用手机按登录页面提示扫码并确认。看到 **账号已登录**、语音状态显示 **就绪** 后即可使用。

已经安装 Decky 的用户，上述步骤可在游戏模式完成。安装包不包含账号、Cookie、二维码或开发者的个人设置；每位使用者登录自己的账号。

登录资料保存在当前设备。普通升级、关闭语音和关闭总开关都不会主动退出账号。登录可能因服务端会话失效而需要重新扫码；无需为了每次输入手动登录。

## 2. 把背键映射为 F7

打开对应游戏的 **控制器设置 → 编辑布局 → 按钮**，启用背键并将一颗背键（例如右下方 R5）映射为键盘 **F7**。不同 Steam 版本的页面名称可能略有区别。

- 使用 **普通按压**。不要设置为长按触发、双击触发、切换保持或连发，插件会自行判断按住、松开和双击。
- 外接键盘可直接使用 F7；某些键盘需按 `Fn + F7`。
- 如果 F7 与游戏冲突，在 **语音设置 → 听写快捷键** 选择其他空闲功能键，再同步修改 Steam Input 映射。不能与键盘输入法的唤醒键或调整键冲突。
- 如果按住背键时波形只闪一下，用 **语音设置 → 检测背键映射** 核对实际输出的功能键，并检查是否误用了只触发一次的命令。

## 3. 按住说话，松开填入

先选中游戏的聊天输入框，让光标位于可以输入文字的位置。仅打开聊天窗口而没有选中输入框，可能无法填入。

| 操作 | 结果 |
| --- | --- |
| 按住 F7 / 映射为 F7 的背键 | 开始录音，显示随声音变化的波形 |
| 松开 | 完成识别，显示“正在转写”，随后将文字填入当前输入框 |
| “正在转写”时再按一次 | 取消本次转写和填入 |
| 录音时打开 Steam 或“…”菜单 | 取消本次听写，系统菜单优先 |
| 关闭“启用语音输入” | 停止语音服务，保留登录资料 |
| 关闭总开关 | 关闭语音并释放插件接管的实体键盘 |

**填入的是草稿，不会替你发送聊天消息。** 确认内容后再用游戏原有的发送键发送。开启语音开关表示待命；按住听写键期间才录音，不是持续录音。

在 **语音设置 → 调整波形位置和透明度** 中拖动预览，或用位置滑块调整。波形位置按画面比例保存，不透明度可设为 20%–100%。

## 4. 清空刚填入的草稿（可选）

双击清空目前仅适配 **《魔兽世界：无限》**，需要随包的 **WoWDeckDraft 0.2.3** 游戏组件；基础语音输入不需要这个组件。

1. 进入该游戏，让插件识别实际游戏目录。
2. 在 **语音设置** 点击 **安装或更新魔兽双击清空组件**。
3. 完整退出并重新进入魔兽，使游戏加载组件。
4. 语音文字填入后，快速点两下同一颗听写键，清空刚填入、尚未发送的当前草稿；然后可以再次按住重说。

也可以从本次 Release 下载 `WoWDeckDraft-2.0.0.zip`，把其中 `WoWDeckDraft` 文件夹放进对应游戏的 `Interface/AddOns/` 目录。压缩包跟随主插件版本命名，组件内部版本仍为 0.2.3。

这不是任意输入框的全选删除或通用撤销：发送消息、切换聊天框、编辑成其他内容或离开游戏后，旧草稿的清空资格会失效。游戏画面没有常驻“清空”或“拖动”按钮。

## 5. 退出登录或更换账号

在 **语音设置 → 退出登录 → 确认退出** 操作。插件会关闭听写，并删除本设备的插件专用登录资料。之后重新选择 **扫码登录**，使用需要的账号即可，无需单独的“切换账号”按钮。

## 常见问题

**一直不显示二维码，或者提示连接失败？**

先检查网络。二维码获取超过时限会显示失败原因，并停止反复启动。选择 **重新连接账号** 重试；已有登录页面时可选 **重新获取二维码**。这两个操作不会主动清除已有账号资料。登录页面由豆包服务控制，页面变化或网络限制也可能影响登录。

**已经选中输入框，却仍填入失败？**

先确认 Steam / 快捷访问菜单已关闭，游戏输入框仍有光标。插件会核对前台窗口和本次剪贴板文字；焦点变化、游戏不接收粘贴、剪贴板被其他软件替换，都可能阻止填入。插件无法直接读取每个游戏编辑框的光标状态，不能保证所有游戏均可填入。

**转写慢或失败？**

查看提示属于连接失败、识别超时还是填入失败。语音识别需要网络和豆包服务响应；当前采用按住期间流式上传、松开后收尾，不必等松开后才上传整段。重试前先确认输入框里是否已有内容，避免重复发送。

**提示缺少系统组件？**

语音依赖 SteamOS 镜像中的 Qt 6 WebEngine、PulseAudio/PipeWire 的 `parec` 接口、X11、GTK 3 和 `xdotool`。不同掌机系统镜像可能不齐全，插件会提示缺失，不会自动修改系统只读分区。语音不可用时，仍可单独使用键盘输入法。

**分享给别人需要发什么？**

只分享 Release 的安装包。不要复制自己设备上的浏览器资料、设置目录、二维码或日志。语音音频发送给豆包识别，键盘与五笔在本机处理；插件没有共享账号或项目中转服务器。语音填入会使用并替换系统剪贴板，详见 [隐私说明](../PRIVACY.md)。

反馈时附上设备、SteamOS、Decky、插件版本及具体错误提示即可；不要提交账号、Cookie、聊天正文或录音。
